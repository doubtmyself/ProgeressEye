# PC Agent - 기능 요구사항 정의서

---

## 1. 개요

PC Agent는 Windows 데스크탑에서 동작하는 Python 기반 경량 프로그램으로, 사용자가 지정한 화면 영역의 **진행바 채움 비율을 OpenCV로 분석**하거나 **OCR로 숫자를 직접 인식**하여 진행률(%)을 산출하고, **Google 로그인 기반**으로 Firebase에 전송한다. 같은 Google 계정의 모바일 앱에서 자동으로 확인 가능하다.

---

## 2. 기능 요구사항

### FR-PC-001: Google 로그인 (Authentication)

| 항목 | 내용 |
|------|------|
| 설명 | Google 계정으로 로그인하여 Firebase 인증 |
| 상세 | - 시스템 기본 브라우저를 통한 Google OAuth 2.0 로그인 |
|  | - 로그인 완료 시 localhost 리다이렉트로 토큰 수신 |
|  | - 인증 토큰 로컬 안전 저장 (재실행 시 자동 로그인) |
|  | - 토큰 만료 시 자동 갱신 (사용자 개입 불필요) |
|  | - 로그아웃 기능 제공 |
|  | - 로그인 상태 트레이 아이콘에 표시 |
| 우선순위 | **필수 (P0)** |

### FR-PC-002: 영역 선택 (Area Selection)

| 항목 | 내용 |
|------|------|
| 설명 | 사용자가 마우스 드래그로 모니터링할 진행바 영역을 지정 |
| 선행조건 | Google 로그인 완료 |
| 상세 | - 반투명 오버레이 표시 후 드래그로 사각형 영역 선택 |
|  | - 선택 영역 미리보기 및 확인/재선택 가능 |
|  | - 멀티 모니터 환경 지원 |
|  | - 선택 영역 좌표 로컬 저장 (재실행 시 복원) |
|  | - 선택 시 채움 색상 / 빈 색상 자동 감지 (수동 조정 가능) |
| 우선순위 | **필수 (P0)** |

### FR-PC-003: 주기적 캡처 (Periodic Capture)

| 항목 | 내용 |
|------|------|
| 설명 | 지정 영역만 설정 주기로 캡처 |
| 상세 | - 캡처 주기: 10초 / 30초 / 1분 (사용자 설정) |
|  | - 지정 영역(예: 300x20px)만 캡처 → 전체 화면 캡처 없음 |
|  | - 캡처 이미지는 메모리 내 처리, 디스크 저장 안 함 |
|  | - CPU 사용률 1% 미만 유지 |
| 우선순위 | **필수 (P0)** |

### FR-PC-004: 진행률 감지 (Bar Analyzer + OCR Reader)
| 항목 | 내용 |
|------|------|
| 설명 | 캡처된 이미지에서 진행률(%)을 산출하는 이중 모드 지원 |
| 바 탐지 모드 | - OpenCV 4전략(Canny+Otsu, 적응형이진화, HSV채도분할, 배경제거)으로 진행바 자동 탐지 |
|  | - Sobel 트랙 확장으로 바 경계 정밀 보정 |
|  | - 슬라이딩 윈도우 전환점 분석으로 채움 비율 계산 (그라데이션 지원) |
|  | - 숫자 없는 진행바, 다국어 환경에서도 동작 |
| OCR 모드 | - pytesseract 기반 숫자 인식 |
|  | - "45%" 형태뿐 아니라 단독 숫자 "45" (0~100 범위)도 감지 |
|  | - "45" + "%" 분리 인식 후 합산 처리 |
|  | - 숫자가 화면에 표시되는 진행바에 적합 |
|  | - 앞뒤 문자가 포함된 텍스트에서도 숫자 추출 (예: '진행르45%완료' → 45%) |
| 공통 | - 분석 실패 시 이전 값 유지 + 재시도 |
|  | - 분석 결과 신뢰도 산출 |
| 우선순위 | **필수 (P0)** |

### FR-PC-005: Firebase 동기화 (Data Sync)

| 항목 | 내용 |
|------|------|
| 설명 | 분석 결과를 Firebase Realtime DB에 전송 |
| 상세 | - 전송 경로: `users/{uid}/tasks/{pcId}/{taskId}` |
|  | - 전송 데이터: 진행률(%), 타임스탬프 |
|  | - 이미지 원본은 절대 전송하지 않음 |
|  | - 네트워크 끊김 시 로컬 큐잉 후 재연결 시 전송 |
|  | - 마지막 전송 상태 트레이에 표시 |
| 우선순위 | **필수 (P0)** |

### FR-PC-006: PC 기기 등록 (Device Registration)

| 항목 | 내용 |
|------|------|
| 설명 | 로그인 시 자동으로 Firebase에 PC 정보 등록 |
| 상세 | - 최초 로그인 시 PC ID 자동 생성 및 등록 |
|  | - 등록 경로: `users/{uid}/devices/{pcId}` |
|  | - PC 이름 설정 가능 (기본값: 컴퓨터 이름) |
|  | - 온라인/오프라인 상태 자동 관리 (Firebase Presence) |
| 우선순위 | **필수 (P0)** |

### FR-PC-007: 원격 명령 수신 (Remote Command)

| 항목 | 내용 |
|------|------|
| 설명 | 모바일에서 보낸 PC 제어 명령 수신 및 실행 |
| 상세 | - 수신 경로: `users/{uid}/commands/{pcId}` |
|  | - 지원 명령: PC 종료, 절전 모드 전환 |
|  | - 명령 수신 시 확인 팝업 표시 (설정으로 비활성화 가능) |
|  | - 명령 실행 결과 Firebase에 피드백 |
| 우선순위 | **2단계 (P1)** |

### FR-PC-008: 시스템 트레이 상주 (System Tray)

| 항목 | 내용 |
|------|------|
| 설명 | 시스템 트레이에 아이콘으로 상주하며 상태 표시 |
| 상세 | - 트레이 아이콘: 모니터링 중 / 일시정지 / 오프라인 상태 구분 |
|  | - 우클릭 메뉴: 영역 재선택, 일시정지, 설정, 로그아웃, 종료 |
|  | - 더블클릭: 메인 창 열기 |
|  | - Windows 시작 시 자동 실행 옵션 |
|  | - 로그인 계정 정보 표시 (이메일) |
| 우선순위 | **필수 (P0)** |

### FR-PC-009: 멀티 태스크 모니터링 (Multi-Task)

| 항목 | 내용 |
|------|------|
| 설명 | 동시에 여러 영역을 모니터링 |
| 상세 | - 최대 5개 영역 동시 모니터링 |
|  | - 각 영역에 라벨 지정 (예: "프리미어 렌더링") |
|  | - 개별 시작/정지 가능 |
| 우선순위 | **3단계 (P2)** |

### FR-PC-010: 진행 멈춤 감지 (Freeze Detection)

| 항목 | 내용 |
|------|------|
| 설명 | 진행률이 일정 시간 변화 없을 때 감지 |
| 상세 | - 설정 시간(기본 5분) 동안 진행률 변화 없으면 "멈춤" 상태 전환 |
|  | - Firebase에 freeze 상태 전송 → 모바일 알림 트리거 |
| 우선순위 | **필수 (P0)** |

## 3. 비기능 요구사항

| ID | 항목 | 기준 |
|----|------|------|
| NFR-PC-001 | CPU 사용률 | 평균 1% 미만, 피크 3% 미만 |
| NFR-PC-002 | 메모리 사용 | 80MB 이하 |
| NFR-PC-003 | 네트워크 사용 | 월 5MB 미만 (일반 사용 기준) |
| NFR-PC-004 | 시작 시간 | 3초 이내 |
| NFR-PC-005 | OS 지원 | Windows 10/11 (64bit) |
| NFR-PC-006 | 설치 | 단일 .exe 파일, 관리자 권한 불필요 |
| NFR-PC-007 | 분석 정확도 | 95% 이상 (일반적 진행바 환경) |
| NFR-PC-008 | 자동 로그인 | 최초 1회 로그인 후 재실행 시 자동 인증 |
| NFR-PC-009 | exe 크기 | Tesseract 번들 미포함 약 15MB, 번들 포함 약 160MB |
