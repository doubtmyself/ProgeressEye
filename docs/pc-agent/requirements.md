# PC Agent - 기능 요구사항 정의서

---

## 1. 개요

PC Agent는 Windows 데스크탑에서 동작하는 Python 기반 경량 프로그램으로, 사용자가 지정한 화면 영역을 주기적으로 캡처하여 OCR로 진행률을 추출하고 Firebase에 전송한다.

---

## 2. 기능 요구사항

### FR-PC-001: 영역 선택 (Area Selection)

| 항목 | 내용 |
|------|------|
| 설명 | 사용자가 마우스 드래그로 모니터링할 영역을 지정 |
| 선행조건 | 프로그램 실행 중 |
| 상세 | - 반투명 오버레이 표시 후 드래그로 사각형 영역 선택 |
|  | - 선택 영역 미리보기 및 확인/재선택 가능 |
|  | - 멀티 모니터 환경 지원 |
|  | - 선택 영역 좌표 로컬 저장 (재실행 시 복원) |
| 우선순위 | **필수 (P0)** |

### FR-PC-002: 주기적 캡처 (Periodic Capture)

| 항목 | 내용 |
|------|------|
| 설명 | 지정 영역만 설정 주기로 캡처 |
| 상세 | - 캡처 주기: 10초 / 30초 / 1분 (사용자 설정) |
|  | - 지정 영역(예: 150x30px)만 캡처 → 전체 화면 캡처 없음 |
|  | - 캡처 이미지는 메모리 내 처리, 디스크 저장 안 함 |
|  | - CPU 사용률 1% 미만 유지 |
| 우선순위 | **필수 (P0)** |

### FR-PC-003: OCR 텍스트 추출 (OCR Engine)

| 항목 | 내용 |
|------|------|
| 설명 | 캡처 이미지에서 진행률(%)과 남은 시간 추출 |
| 상세 | - 숫자 + % 패턴 인식 (예: "73%", "73.5%") |
|  | - 시간 패턴 인식 (예: "00:42:15", "42 min remaining") |
|  | - 이미지 전처리: 그레이스케일, 이진화, 노이즈 제거 |
|  | - OCR 실패 시 이전 값 유지 + 재시도 |
|  | - 인식 신뢰도(confidence) 임계값 설정 |
| 우선순위 | **필수 (P0)** |

### FR-PC-004: Firebase 동기화 (Data Sync)

| 항목 | 내용 |
|------|------|
| 설명 | OCR 결과를 Firebase Realtime DB에 전송 |
| 상세 | - 전송 데이터: 진행률(%), 남은시간, 타임스탬프 |
|  | - 이미지 원본은 절대 전송하지 않음 |
|  | - 네트워크 끊김 시 로컬 큐잉 후 재연결 시 전송 |
|  | - 마지막 전송 상태 트레이에 표시 |
| 우선순위 | **필수 (P0)** |

### FR-PC-005: 기기 페어링 (Device Pairing)

| 항목 | 내용 |
|------|------|
| 설명 | 모바일 앱과 연동하기 위한 코드 기반 페어링 |
| 상세 | - 6자리 숫자 페어링 코드 생성 |
|  | - 코드 유효시간: 5분 |
|  | - 페어링 완료 후 영구 연동 (재페어링 불필요) |
|  | - 여러 모바일 기기와 페어링 가능 |
| 우선순위 | **필수 (P0)** |

### FR-PC-006: 원격 명령 수신 (Remote Command)

| 항목 | 내용 |
|------|------|
| 설명 | 모바일에서 보낸 PC 제어 명령 수신 및 실행 |
| 상세 | - 지원 명령: PC 종료, 절전 모드 전환 |
|  | - 명령 수신 시 확인 팝업 표시 (설정으로 비활성화 가능) |
|  | - 명령 실행 결과 Firebase에 피드백 |
| 우선순위 | **2단계 (P1)** |

### FR-PC-007: 시스템 트레이 상주 (System Tray)

| 항목 | 내용 |
|------|------|
| 설명 | 시스템 트레이에 아이콘으로 상주하며 상태 표시 |
| 상세 | - 트레이 아이콘: 모니터링 중 / 일시정지 / 오프라인 상태 구분 |
|  | - 우클릭 메뉴: 영역 재선택, 일시정지, 설정, 종료 |
|  | - 더블클릭: 메인 창 열기 |
|  | - Windows 시작 시 자동 실행 옵션 |
| 우선순위 | **필수 (P0)** |

### FR-PC-008: 멀티 태스크 모니터링 (Multi-Task)

| 항목 | 내용 |
|------|------|
| 설명 | 동시에 여러 영역을 모니터링 |
| 상세 | - 최대 5개 영역 동시 모니터링 |
|  | - 각 영역에 라벨 지정 (예: "프리미어 렌더링") |
|  | - 개별 시작/정지 가능 |
| 우선순위 | **3단계 (P2)** |

### FR-PC-009: 진행 멈춤 감지 (Freeze Detection)

| 항목 | 내용 |
|------|------|
| 설명 | 진행률이 일정 시간 변화 없을 때 감지 |
| 상세 | - 설정 시간(기본 5분) 동안 진행률 변화 없으면 "멈춤" 상태 전환 |
|  | - Firebase에 freeze 상태 전송 → 모바일 알림 트리거 |
| 우선순위 | **필수 (P0)** |

## 3. 비기능 요구사항

| ID | 항목 | 기준 |
|----|------|------|
| NFR-PC-001 | CPU 사용률 | 평균 1% 미만, 피크 3% 미만 |
| NFR-PC-002 | 메모리 사용 | 100MB 이하 |
| NFR-PC-003 | 네트워크 사용 | 월 10MB 미만 (일반 사용 기준) |
| NFR-PC-004 | 시작 시간 | 5초 이내 |
| NFR-PC-005 | OS 지원 | Windows 10/11 (64bit) |
| NFR-PC-006 | 설치 | 단일 .exe 파일, 관리자 권한 불필요 |
| NFR-PC-007 | OCR 정확도 | 95% 이상 (일반적 진행바 환경) |
