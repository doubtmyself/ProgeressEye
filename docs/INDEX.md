# ProgressEye 문서 인덱스

이 문서는 "어떤 문서를 먼저 봐야 하는지"를 빠르게 찾기 위한 시작점입니다.

## 작업 규칙

- 문서/코드 작업 시작 전, **항상 이 파일(`docs/INDEX.md`)부터 먼저 읽는다**.
- 이후 플랫폼에 맞는 인덱스로 이동한다.
  - PC: `docs/pc-agent/INDEX.md`
  - 모바일: `docs/mobile-app/INDEX.md`
  - 백엔드: `docs/backend/INDEX.md`

## 빠른 이동

- 프로젝트 개요: `docs/overview.md`
- 제품 기획서: `docs/product-plan.md`
- PC 앱 문서: `docs/pc-agent/INDEX.md`
- 모바일 앱 문서: `docs/mobile-app/INDEX.md`
- 백엔드/Firebase/정책 문서: `docs/backend/INDEX.md`

## 목적별 바로가기

| 내가 하고 싶은 일 | 바로 볼 문서 |
|---|---|
| PC 앱 실행/빌드 | `docs/pc-agent/INDEX.md` -> 실행/배포 |
| PC 진행률 감지 로직 이해 | `docs/pc-agent/INDEX.md` -> 감지 파이프라인 |
| 모바일 화면/상태 흐름 이해 | `docs/mobile-app/INDEX.md` -> 화면 구조/상태관리 |
| 모바일 빌드/배포 | `docs/mobile-app/INDEX.md` -> 빌드/배포 |
| Firebase 데이터 구조 확인 | `docs/backend/INDEX.md` -> 데이터 스키마 |
| Cloud Functions 동작 확인 | `docs/backend/INDEX.md` -> Functions |
| 탈퇴/유예/재가입 정책 확인 | `docs/backend/INDEX.md` -> 계정 정책 |
| 개인정보처리방침 확인 | `docs/privacy-policy-ko.md`, `docs/privacy-policy-en.md` |
| 제품 기획/로드맵 확인 | `docs/product-plan.md` |
| PC 스토어 문안 수정 | `docs/pc-agent/topics/store-listing.md` |
