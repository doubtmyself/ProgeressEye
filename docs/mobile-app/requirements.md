# Mobile App (Android) - 기능 요구사항 정의서

---

## 1. 개요

ProgressEye 모바일 앱은 Android 기반으로, **Google 로그인**으로 인증하여 같은 계정에 등록된 PC의 작업 진행 상황을 실시간으로 확인하고, 완료 시 푸시 알림을 받으며, 원격으로 PC를 제어할 수 있는 대시보드 앱이다.

---

## 2. 기능 요구사항

### FR-MOB-001: Google 로그인 (Authentication)

| 항목 | 내용 |
|------|------|
| 설명 | Google 계정으로 로그인하여 Firebase 인증 |
| 상세 | - Android 네이티브 Google Sign-In (One Tap UI) |
|  | - 로그인 완료 시 Firebase Auth에 자동 등록 |
|  | - 같은 Google 계정의 PC들이 자동으로 대시보드에 표시 |
|  | - 자동 로그인 유지 (재실행 시 로그인 불필요) |
|  | - 로그아웃 / 계정 전환 기능 |
|  | - **계정당 1개 모바일 세션**: 다른 기기에서 로그인 시 기존 세션 교체 (확인 후) |
| 우선순위 | **필수 (P0)** |

### FR-MOB-002: 대시보드 (Dashboard)

| 항목 | 내용 |
|------|------|
| 설명 | 내 계정에 등록된 모든 PC의 진행 상황을 한눈에 표시 |
| 상세 | - PC별 카드 형태로 목록 표시 |
|  | - 각 카드: PC 이름, 작업 라벨, 진행률(%), 진행바 시각화 |
|  | - PC 온라인/오프라인 상태 표시 |
|  | - 실시간 업데이트 (Firebase `users/{uid}/devices/{deviceId}/tasks` 리스너) |
|  | - 당겨서 새로고침 (Pull-to-refresh) |
|  | - PC 미등록 시 안내 메시지 표시 ("PC Agent에서 같은 Google 계정으로 로그인하세요") |
| 우선순위 | **필수 (P0)** |

### FR-MOB-003: 작업 상세 화면 (Task Detail)

| 항목 | 내용 |
|------|------|
| 설명 | 개별 작업의 상세 진행 정보 표시 |
| 상세 | - 진행률 변화 그래프 (시간별 추이) |
|  | - 예상 완료 시간 표시 (진행 속도 기반 추정) |
|  | - 작업 시작 시간, 경과 시간 |
|  | - 현재 상태: 진행중 / 멈춤 / 완료 / 오류 |
| 우선순위 | **2단계 (P1)** |

### FR-MOB-004: 푸시 알림 (Push Notification)

| 항목 | 내용 |
|------|------|
| 설명 | 주요 이벤트 발생 시 푸시 알림 수신 |
| 상세 | - **완료 알림**: 진행률 100% 도달 시 |
|  | - **멈춤 알림**: 진행률 변화 없음 감지 시 |
|  | - **오프라인 알림**: PC 연결 끊김 시 |
|  | - 알림별 개별 on/off 설정 |
|  | - 방해금지 시간대 설정 |
|  | - 알림 클릭 시 해당 작업 상세 화면 이동 |
| 우선순위 | **필수 (P0)** |

### FR-MOB-005: 원격 PC 제어 (Remote Command)

| 항목 | 내용 |
|------|------|
| 설명 | 모바일에서 PC에 명령 전송 |
| 상세 | - **모니터링 시작/정지**: `users/{uid}/commands/monitor` 경로에 `{action: "start" \| "stop", ts}` 기록 |
|  | - **스크린샷 요청**: FR-MOB-008 참조 |
|  | - **절전 모드**: `users/{uid}/commands/sleep` 경로에 `{targetDeviceId, ts}` 기록 |
|  | - **PC 종료**: `users/{uid}/commands/shutdown` 경로에 `{targetDeviceId, ts}` 기록. 종료 전 확인 AlertDialog 표시 |
|  | - 명령 경로: `users/{uid}/commands/` (PC Agent가 SSE로 실시간 수신) |
|  | - sleep/shutdown은 targetDeviceId 필수 포함 (PC Agent에서 자기 기기 여부 검증) |
| 우선순위 | **필수 (P0)** — 모든 명령 구현 완료 |

### FR-MOB-006: 설정 (Settings)

| 항목 | 내용 |
|------|------|
| 설명 | 앱 동작 설정 관리 |
| 상세 | - 알림 설정 (종류별 on/off, 방해금지) |
|  | - 연결된 PC 관리 (이름 변경, 등록 해제) |
|  | - 계정 정보 표시 (이메일, 프로필) |
|  | - 로그아웃 / 계정 전환 |
|  | - 테마 설정 (라이트/다크) |
|  | - **회원 탈퇴**: 계정 삭제 기능 (로그아웃과 동일 스타일의 빨간 OutlinedButton) |
|  | - 탈퇴 시: forceLogout 명령 전송 → 2초 대기 → RTDB 전체 삭제 → Firebase Auth 삭제 → signOut |
|  | - 모든 연결된 기기 강제 로그아웃 |
|  | - 앱 정보 및 버전 |
| 우선순위 | **필수 (P0)** |

### FR-MOB-007: 홈 위젯 (Home Widget)

| 항목 | 내용 |
|------|------|
| 설명 | 앱 실행 없이 홈 화면에서 진행률 확인 |
| 상세 | - 작은 위젯: 단일 작업 진행률 표시 |
|  | - 큰 위젯: 전체 PC 목록 요약 |
|  | - 위젯 탭 시 앱 대시보드로 이동 |
|  | - 백그라운드 자동 업데이트 |
| 우선순위 | **3단계 (P2)** |

### FR-MOB-008: 스크린샷 요청 (Screenshot Request)

| 항목 | 내용 |
|------|------|
| 설명 | 모바일에서 PC 화면 스크린샷을 요청하고 확인 |
| 상세 | - 대시보드 또는 작업 상세에서 "스크린샷" 버튼 탭 |
|  | - `users/{uid}/commands/screenshot` 경로에 `{ts: <timestamp>}` 기록 |
|  | - PC Agent가 SSE로 명령 수신 → 전체 화면 캡처 → JPEG 압축 → Firebase Storage 업로드 |
|  | - 업로드 완료 후 `users/{uid}/devices/{deviceId}/screenshots/latest` 에 `{url, ts}` 기록 |
|  | - 모바일 앱이 RTDB 리스너로 URL 수신 → 이미지 표시 |
|  | - 요청 중 로딩 인디케이터 표시 (요청 → URL 수신까지) |
|  | - 이미지 핀치-투-줌 지원 |
|  | - PC 오프라인 시 요청 불가 안내 |
| 우선순위 | **필수 (P0)** |

### FR-MOB-009: 알림 런타임 권한 (Notification Permission)

| 항목 | 내용 |
|------|------|
| 설명 | Android 13+ (API 33) 알림 권한 런타임 요청 |
| 상세 | - 앱 시작 시 `POST_NOTIFICATIONS` 권한 확인 |
|  | - 권한 미부여 시 시스템 권한 요청 다이얼로그 표시 |
|  | - 권한 거부 시에도 앱 사용 가능 (FCM 알림만 비활성) |
| 우선순위 | **구현 완료** |

### FR-MOB-010: 구독 상태 조회 (Plan Query)

| 항목 | 내용 |
|------|------|
| 설명 | Firestore에서 사용자 구독 상태(free/pro) 조회 |
| 상세 | - 경로: Firestore `users/{uid}` 문서의 `plan` 필드 |
|  | - RTDB에서 Firestore로 마이그레이션됨 |
|  | - 문서 미존재 시 기본값 "free" |
| 우선순위 | **구현 완료** |

## 3. 비기능 요구사항

| ID | 항목 | 기준 |
|----|------|------|
| NFR-MOB-001 | 앱 시작 시간 | 2초 이내 (콜드 스타트) |
| NFR-MOB-002 | 배터리 소모 | 백그라운드 1시간당 1% 미만 |
| NFR-MOB-003 | 데이터 소모 | 포그라운드: 월 5MB 미만 / 백그라운드: 0 (RTDB 리스너 해제). 완료/프리징 알림은 FCM 푸시로 처리. |
| NFR-MOB-004 | 최소 OS | Android 8.0 (API 26) 이상 |
| NFR-MOB-005 | 알림 지연 | 완료 감지 후 3초 이내 푸시 수신 |
| NFR-MOB-006 | 오프라인 대응 | 마지막 동기화 데이터 캐시 표시 |
| NFR-MOB-007 | 접근성 | Material Design 3 접근성 가이드 준수 |
| NFR-MOB-008 | 자동 로그인 | 최초 1회 로그인 후 재실행 시 자동 인증 |

## 4. 화면 흐름 (Screen Flow)

```
앱 시작
  │
  ├─ 로그인 안됨 ──→ [로그인 화면] ──→ Google Sign-In ──→ 인증 완료
  │                                                          │
  └─ 로그인 됨 ──→ [대시보드] <────────────────────────────────┘
                      │
                      ├── PC 있음 → PC 카드 목록 표시
                      │     │
                      │     └── 카드 탭 ──→ [작업 상세]
                      │
                      ├── PC 없음 → "PC Agent에서 같은 계정으로 로그인하세요" 안내
                      │
                      └── 하단 네비게이션 ──→ [알림 화면] / [설정 화면]
                                            │
                                            ├── 알림 설정
                                            ├── PC 관리
                                            ├── 계정 (로그아웃/전환)
                                            └── 테마 / 정보
```
