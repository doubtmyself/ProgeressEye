# Mobile App (Android) - 기능 요구사항 정의서

---

## 1. 개요

ProgressEye 모바일 앱은 Android 기반으로, 연결된 PC의 작업 진행 상황을 실시간으로 확인하고, 완료 시 푸시 알림을 받으며, 원격으로 PC를 제어할 수 있는 대시보드 앱이다.

---

## 2. 기능 요구사항

### FR-MOB-001: PC 페어링 (Device Pairing)

| 항목 | 내용 |
|------|------|
| 설명 | PC Agent에서 생성한 6자리 코드로 연동 |
| 상세 | - 6자리 숫자 코드 입력 |
|  | - 코드 유효성 실시간 검증 |
|  | - 연결 성공 시 PC 정보 자동 저장 |
|  | - 여러 대의 PC 등록 가능 |
| 우선순위 | **필수 (P0)** |

### FR-MOB-002: 대시보드 (Dashboard)

| 항목 | 내용 |
|------|------|
| 설명 | 연결된 모든 PC의 진행 상황을 한눈에 표시 |
| 상세 | - PC별 카드 형태로 목록 표시 |
|  | - 각 카드: PC 이름, 작업 라벨, 진행률(%), 남은 시간 |
|  | - 진행률 바 시각화 (원형 또는 선형) |
|  | - PC 온라인/오프라인 상태 표시 |
|  | - 실시간 업데이트 (Firebase Realtime DB 리스너) |
|  | - 당겨서 새로고침 (Pull-to-refresh) |
| 우선순위 | **필수 (P0)** |

### FR-MOB-003: 작업 상세 화면 (Task Detail)

| 항목 | 내용 |
|------|------|
| 설명 | 개별 작업의 상세 진행 정보 표시 |
| 상세 | - 진행률 변화 그래프 (시간별 추이) |
|  | - 예상 완료 시간 표시 |
|  | - 작업 시작 시간, 경과 시간 |
|  | - 현재 상태: 진행중 / 멈춤 / 완료 / 오류 |
| 우선순위 | **2단계 (P1)** |

### FR-MOB-004: 푸시 알림 (Push Notification)

| 항목 | 내용 |
|------|------|
| 설명 | 주요 이벤트 발생 시 푸시 알림 수신 |
| 상세 | - **완료 알림**: 진행률 100% 도달 시 |
|  | - **멈춤 알림**: 진행률 변화 없음 감지 시 |
|  | - **오프라인 알림**: PC 연결 끊김 시 |
|  | - 알림별 개별 on/off 설정 |
|  | - 방해금지 시간대 설정 |
|  | - 알림 클릭 시 해당 작업 상세 화면 이동 |
| 우선순위 | **필수 (P0)** |

### FR-MOB-005: 원격 PC 제어 (Remote Command)

| 항목 | 내용 |
|------|------|
| 설명 | 모바일에서 PC에 명령 전송 |
| 상세 | - **PC 종료**: 작업 완료 후 원격 종료 |
|  | - **절전 모드**: 절전 모드 전환 |
|  | - 명령 전송 전 확인 다이얼로그 표시 |
|  | - 명령 실행 결과 피드백 (성공/실패) |
| 우선순위 | **2단계 (P1)** |

### FR-MOB-006: 설정 (Settings)

| 항목 | 내용 |
|------|------|
| 설명 | 앱 동작 설정 관리 |
| 상세 | - 알림 설정 (종류별 on/off, 방해금지) |
|  | - 연결된 PC 관리 (이름 변경, 연결 해제) |
|  | - 테마 설정 (라이트/다크) |
|  | - 앱 정보 및 버전 |
| 우선순위 | **필수 (P0)** |

### FR-MOB-007: 홈 위젯 (Home Widget)

| 항목 | 내용 |
|------|------|
| 설명 | 앱 실행 없이 홈 화면에서 진행률 확인 |
| 상세 | - 작은 위젯: 단일 작업 진행률 표시 |
|  | - 큰 위젯: 전체 PC 목록 요약 |
|  | - 위젯 탭 시 앱 대시보드로 이동 |
|  | - 백그라운드 자동 업데이트 |
| 우선순위 | **3단계 (P2)** |

## 3. 비기능 요구사항

| ID | 항목 | 기준 |
|----|------|------|
| NFR-MOB-001 | 앱 시작 시간 | 2초 이내 (콜드 스타트) |
| NFR-MOB-002 | 배터리 소모 | 백그라운드 1시간당 1% 미만 |
| NFR-MOB-003 | 데이터 소모 | 월 5MB 미만 (일반 사용) |
| NFR-MOB-004 | 최소 OS | Android 8.0 (API 26) 이상 |
| NFR-MOB-005 | 알림 지연 | 완료 감지 후 3초 이내 푸시 수신 |
| NFR-MOB-006 | 오프라인 대응 | 마지막 동기화 데이터 캐시 표시 |
| NFR-MOB-007 | 접근성 | Material Design 3 접근성 가이드 준수 |

## 4. 화면 흐름 (Screen Flow)

```
앱 시작
  │
  ├─ 페어링 없음 ──→ [페어링 화면] ──→ 코드 입력 ──→ 연동 완료
  │                                                      │
  └─ 페어링 완료 ──→ [대시보드] <─────────────────────────┘
                        │
                        ├── PC 카드 탭 ──→ [작업 상세]
                        │
                        ├── + 버튼 ──→ [PC 추가 페어링]
                        │
                        └── 설정 아이콘 ──→ [설정 화면]
                                              │
                                              ├── 알림 설정
                                              ├── PC 관리
                                              └── 테마 / 정보
```
