# ProgressEye 기획서

## 프로젝트 정의

- 프로젝트명: ProgressEye
- 부제: 화면 전체 공유 없이 진행률만 전달하는 초경량 원격 모니터링 알리미

## 배경과 목적

- Adobe CC 알림 서비스 축소/중단으로 렌더링 대기 확인 불편 증가
- 기존 원격 제어 앱은 전체 화면 노출, 높은 데이터 소모, 무거운 사용감 문제 존재
- 목표는 지정 영역의 진행률만 추출해 모바일에서 실시간으로 확인하는 경량 워크플로우 구축

## 핵심 타겟

- 영상 편집자, 모션 그래픽 디자이너
- 3D 아티스트
- AI 연구원
- 데이터 작업자(대용량 업/다운로드, 장시간 쿼리)

## 핵심 시스템 아키텍처

### PC Agent

- Google 로그인 기반 인증
- 사용자가 지정한 영역만 캡처(예: 300x20)
- 진행률 분석 이중 모드
  - OpenCV 기반 진행바 픽셀 분석
  - OCR 기반 숫자 추출(혼합 문자열에서도 숫자 추출)
- 이미지 원본이 아니라 진행률 수치 중심 동기화

### Cloud (Firebase)

- Google 인증 연동
- 진행률, 예상 완료 시점, 온라인 상태 저장
- 완료 시점 푸시 알림 트리거

### Mobile App (Android)

- 동일 Google 계정으로 PC 자동 연결
- 여러 PC 상태 대시보드 제공
- 완료/정체 알림 제공
- 원격 액션(종료/절전/스크린샷 요청) 제공

## 차별점

- 화면 전체 원격 스트리밍 없이 진행률만 전달
- 낮은 데이터 사용량
- 보안 노출 최소화(영역 기반)
- 다양한 툴에 범용 적용(진행바 표시만 있으면 적용 가능)

## 단계별 로드맵

### 1단계: MVP

- PC/모바일 Google 로그인 연동
- PC 영역 캡처 및 분석 엔진 구축
- Firebase 연동
- 모바일 기본 대시보드 구현

### 2단계: 연동 고도화

- 완료/정체 알림 강화
- 원격 제어 기능 보강
- 설정/알림 커스터마이징

### 3단계: 상용화

- PC 실행 파일 패키징 강화
- 다국어/위젯 확장
- 스토어 배포 운영
