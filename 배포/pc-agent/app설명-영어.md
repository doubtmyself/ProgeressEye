# ProgressEye (PC Agent) - Store Description (EN)

## Short Description
Monitor your PC task progress from mobile in real time.

## Full Description
ProgressEye PC Agent connects your Windows PC with the ProgressEye mobile app. It tracks task progress on your screen and syncs status to mobile through Firebase in real time.

You can monitor long-running tasks remotely, request screenshots from your phone, and receive alerts when progress completes or stalls.

## Product Features
- Real-time PC progress monitoring from your mobile device
- Google sign-in and secure cloud sync with Firebase
- Remote screenshot request from mobile to PC
- Supports both progress-bar detection and OCR percentage tracking
- Device status and alert notifications in real time

## How It Works
1. Sign in with Google on PC and mobile.
2. Register your PC device.
3. Start monitoring selected screen regions.
4. Check progress and alerts from the mobile app.
