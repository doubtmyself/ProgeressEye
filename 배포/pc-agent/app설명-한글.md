# ProgressEye (PC Agent) - 스토어 설명서 (KO)

## 짧은 설명
모바일에서 PC 작업 진행률을 실시간으로 확인하세요.

## 상세 설명
ProgressEye PC Agent는 Windows PC와 ProgressEye 모바일 앱을 연결해, 화면 기반 작업 진행률을 감지하고 Firebase를 통해 실시간 동기화합니다.

장시간 작업을 원격으로 모니터링하고, 모바일에서 스크린샷 요청을 보내며, 완료/정체 알림을 받을 수 있습니다.

## 주요 기능
- 모바일에서 PC 진행률 실시간 확인
- Google 로그인 및 Firebase 기반 보안 동기화
- 모바일에서 PC로 원격 스크린샷 요청
- 진행바 인식 + OCR 퍼센트 인식 모드 지원
- 기기 상태 및 알림 실시간 제공

## 사용 방법
1. PC와 모바일에서 Google 로그인
2. PC 기기 등록
3. 화면 영역 선택 후 모니터링 시작
4. 모바일에서 진행률/알림 확인
