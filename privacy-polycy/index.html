ProgressEye 개인정보처리방침

시행일: 2026-02-28

ProgressEye(이하 "서비스")는 이용자의 개인정보를 중요하게 생각하며, 관련 법령을 준수합니다.

1. 수집하는 개인정보 항목

  1. 계정/식별 정보: 이메일, 표시 이름, Firebase UID
  2. 기기 및 사용 정보: device_id, 기기 상태, 앱 버전, 플랫폼, 모니터링 설정/상태
  3. 원격 기능 데이터: 원격 스크린샷 이미지(JPEG), URL, 생성 시각, 명령 데이터
  4. 광고 관련 정보(모바일): AdMob SDK에서 처리하는 광고 식별자/성과 정보

2. 개인정보 이용 목적

  1. 로그인/본인 식별 및 계정 연동
  2. 모바일-PC 동기화 및 원격 제어 기능 제공
  3. 서비스 운영, 장애 대응, 보안 및 부정 이용 방지
  4. 무료 서비스 운영을 위한 광고 제공(모바일 앱)

3. 보관 및 파기

서비스 제공에 필요한 기간 동안 보관하며, 목적 달성 또는 삭제 요청 시 지체 없이 파기합니다.

4. 외부 서비스

  • Google Firebase (Authentication, Realtime Database, Cloud Storage, Cloud Messaging)
  • Google OAuth (로그인)
  • Google AdMob (모바일 광고)
  • Google 개인정보처리방침
  • Firebase 데이터 처리
  • AdMob 데이터/정책
