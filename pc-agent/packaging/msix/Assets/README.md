# MSIX Assets

This folder is used for Microsoft Store/MSIX image assets.

The packaging script `packaging/msix/make_msix.ps1` auto-generates these files
when missing:

- `StoreLogo.png` (50x50)
- `Square44x44Logo.png` (44x44)
- `Square150x150Logo.png` (150x150)

Replace auto-generated placeholders with your final branded assets before
submitting to Partner Center.
